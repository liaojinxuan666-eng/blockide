# BLOCKIDE — terminal edition

一个**终端风格**的积木式 C / C++ / Swift IDE。黑底绿字、ASCII 边框、键盘驱动，拖积木拼程序，实时生成代码，代码与积木双向同步，内置解释器直接运行。

在线访问：https://liaojinxuan666-eng.github.io/blockide/

## 运行

```bash
cd blockide
node server.js
# 浏览器打开 http://localhost:3000
```

零依赖，兼容 Node.js 18+。

## 设计理念

界面完全是终端风格（TUI look）：等宽字体、黑底荧光绿、扫描线特效、ASCII 方角边框、命令栏与状态栏。**全程可用键盘操作**（也保留鼠标拖拽）。三栏分屏：

```
┌ BLOCKS ┐  ┌ CANVAS ┐         ┌ SOURCE ┐
│ 积木库  │  │ 积木画布 │         │ 代码    │
│        │  │        │         │────────│
│        │  │        │         │ OUTPUT │
└────────┘  └────────┘         └────────┘
```

## 键盘快捷键

| 按键 | 功能 |
|---|---|
| `Tab` / `Shift+Tab` | 在三个面板间切换焦点 |
| `↑` / `↓` | 在积木树 / 积木库中导航 |
| `Enter` | 添加选中积木 / 编辑字段 |
| `Space` | 从积木库添加选中积木 |
| `Delete` / `Backspace` | 删除光标积木 |
| `e` | 进入代码编辑模式 |
| `Ctrl+S` | 应用代码编辑 / 导出源码 |
| `Esc` | 取消编辑 / 关闭浮层 |
| `F1` | 快捷键帮助 |
| `F2` | 示例程序选择 |
| `F5` / `r` | 运行程序 |
| `u` / `Ctrl+Z` | 撤销 |
| `Ctrl+Shift+Z` | 重做 |
| `1` / `2` / `3` | 切换 C / C++ / Swift |
| `c` | 复制代码 |

## 核心功能

- **积木拖拽拼装**：Pointer Events，兼容鼠标 / 触屏
- **三种语言代码生成**：类型映射、printf/cout/print、循环/条件语法各自适配
- **代码 ↔ 积木真双向**：编辑代码点「应用」即可反解析回积木树
- **内置解释器**：无需编译器，变量/循环/条件/数组/表达式求值
- **撤销 / 重做**：60 步历史
- **30+ 种积木**：流程、I/O、变量、数组、控制、运算、函数
- **5 个示例**：累加、阶乘、数组遍历、斐波那契、逻辑比较
- **导入 / 导出**：源码文件与积木互转
- **localStorage 持久化**

## 技术实现

零依赖四层架构：

| 文件 | 职责 |
|---|---|
| `js/blocks.js` | 积木模型、分类、示例程序 |
| `js/generators.js` | 积木树 → C/C++/Swift + 行号映射 |
| `js/engine.js` | 积木树解释器 |
| `js/parser.js` | 源码 → 积木树（词法分析 + 递归下降解析） |
| `js/app.js` | 终端风格渲染、键盘驱动、拖拽、双向同步 |

已通过 5 示例 × 3 语言 = 15 组「生成→反解析→运行」往返一致性测试。

## 从原型到 iOS App

纯前端架构，可用 Capacitor 打包（`npx cap add ios`，需 macOS + Xcode）。真机编译真实代码需对接 WebAssembly 编译器（clang.wasm / SwiftWasm）。
